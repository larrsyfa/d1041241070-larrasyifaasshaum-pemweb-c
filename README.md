# Website Review Buku

Sistem informasi penilaian dan ulasan buku berbasis web. Pengguna dapat mencari buku, melihat informasi buku, lalu memberikan rating dan ulasan setelah membacanya. Konsepnya seperti Goodreads atau Bookmory.


## Fitur 

Pengguna

1. Register, login, dan logout
2. Melihat katalog dan mencari buku berdasarkan judul atau penulis
3. Melihat detail buku, sinopsis, dan rata-rata rating
4. Memberikan rating 1–5 dan menulis review
5. Mengedit dan menghapus review sendiri

Admin

1. Menambah, mengubah, dan menghapus buku
2. Melihat daftar pengguna
3. Mengelola review
